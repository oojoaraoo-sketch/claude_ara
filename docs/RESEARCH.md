# 탐색·개선 기록 (주간 예약 작업 "콘텐츠 고도화 탐색"이 갱신)

> 쓸 만한 것은 아래 대기열에 넣어 한 주에 하나씩 구현한다. 외부 코드는 그대로 설치·실행하지 않고, 읽고 이해한 뒤 직접 구현한다.
